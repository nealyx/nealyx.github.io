Algorithms & Competitive Programming

Write once. Submit.

USACO Platinum-level problem solving in C++, with resources for anyone working through the same ideas.

Codeforces · lethalboy ↗USACO Platinum

Competitive programming is where algorithms stop being abstract. A time limit makes you care about O(n log n) vs O(n²). A wrong answer on test 47 makes you find the edge case you missed.

I compete on Codeforces as lethalboy ↗ and reached USACO Platinum in 2026. Most of my practice is in C++.

C++ resources I use

A short list of what's actually useful, rather than an exhaustive catalogue.

Getting started

  • USACO Guide ↗ — the best structured path from Bronze to Platinum. Free and comprehensive.
  • CP-Algorithms ↗ — clean explanations and C++ implementations of standard algorithms and data structures.
  • C++ STL cheat sheet ↗ — the standard library is your friend. Know it.

Key topics at Platinum level

  • Graph algorithms — Dijkstra, Bellman-Ford, strongly connected components, bridges and articulation points.
  • Trees — LCA, HLD, Euler tour, centroid decomposition.
  • Dynamic programming — bitmask DP, interval DP, DP on trees, divide-and-conquer optimization.
  • Data structures — segment trees (lazy propagation), BIT/Fenwick trees, DSU (union-find), sparse tables.
  • Math — modular arithmetic, combinatorics, matrix exponentiation, number theory (sieve, Euler's totient).
  • Strings — hashing, KMP, Z-algorithm, suffix arrays.

Practice

  • Codeforces Problemset ↗ — filter by rating. Aim slightly above your current level.
  • USACO Problems ↗ — the official archive. Every past contest, sorted by division.
  • AtCoder DP Contest ↗ — 26 DP problems covering most standard patterns. A good benchmark.

One template

Most of my submissions start from a lightweight template. The main things: fast I/O, a few type aliases, and nothing else. Avoid bloated templates — they hide bugs.

#include <bits/stdc++.h>
using namespace std;
typedef long long ll;
typedef pair<int,int> pii;
#define all(x) (x).begin(),(x).end()

int main(){
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    // ...
}
