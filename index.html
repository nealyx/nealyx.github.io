What does a score actually measure? What evidence makes a result worth trusting? A few projects exploring those questions.

Math Reward Hacking

Saved-output case study

When a reward improves, did the answer improve? Follow one saved response through different scoring rules to see how completion limits and answer extraction change the result.

Read the walkthrough Code & evidence
Scope & limitations

Measurement choices materially affect the comparison. The study does not establish consistent reward hacking. Three training-seed pairs limit generalization; model weights are not distributed. The repository includes saved completions, analyses, and offline verification.

ReviewOps

Local prototype · researcher pilot pending

What was reviewed, and which evidence did it use? A local workspace for experiment handoffs: compare submissions, keep review notes, and preserve earlier evidence and decisions.

Try the walkthrough Download Code
Scope & limitations

Startup cases are synthetic. File hashes check content identity, not scientific correctness. The app runs locally with Python and includes offline backup and restore. Researcher adoption and time savings have not been measured.

Multimodal Response Lab

Runnable pipeline · synthetic demo

Can a signal pipeline stay inspectable when its inputs become unreliable? A camera-free walkthrough follows observations and event timing through scoring, quality checks, and reporting.

Run the offline walkthrough
Scope & limitations

Face, gaze, and head-pose proxies are not validated measures of attention, emotion, or cognition. Heuristic scores and sensor quality remain separate. Synthetic output demonstrates software behavior, not human performance.

Formalization Evaluation Robustness

Research design · documentation only

Does an evaluator's verdict change when a statement's presentation changes but its meaning does not? A proposed study with unchanged-input controls and a plan for inspectable evidence.

Read the research design
Scope & limitations

The public repository is a documentation scaffold. No runnable evaluator, proof certificates, dataset, tests, or experimental findings are released there.
